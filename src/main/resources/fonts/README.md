# Noto Sans

`NotoSans-Regular.ttf` é usada nos resumos PDF para preservar acentos e nomes sem depender das fontes instaladas no servidor.

Origem: [Noto Fonts](https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf).
